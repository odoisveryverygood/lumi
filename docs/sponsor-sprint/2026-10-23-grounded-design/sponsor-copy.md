# Evidence-backed description

Flare uses Gemini 4 Argon to reason over a source keyboard assembly, complete included documentation, uploaded design files and measured tool feedback in one conversation. A proposed charging change can fit geometrically while violating a documented battery limit. Flare checks both, asks the live model to revise, and keeps Apply disabled if the requirements still conflict. Clickable excerpts expose the exact source/page. An explicit visual review submits the actual rendered canvas with the documents and distinguishes visible observations from numeric checks.

The demonstrated workflow targets makers modifying an existing keyboard. It does not certify working hardware. No measured comparison establishes that a smaller model could not solve this example; no model-superiority, maker interview, time-saving or hackathon eligibility claim is made. The three-minute pitch is in docs/THREE_MINUTE_DEMO.md and uses the real product without slides.
