# Gemini integration description

Flare helps a maker inspect a physical object, talk to its components and explore a proposed change in the same 3D scene. Source-backed design checks are available for the curated hardware study; generated objects remain clearly labeled conceptual illustrations.

Gemini 4 Argon generates a custom part graph and geometry from one prompt. Flare streams real, individually validated components into a preview, then checks the finished graph before opening editing. Priority processing is optional, with the provider's actual tier and token usage recorded. Compact geometry preserves coordinates and materials while removing repeated JSON labels.

Live cassette-player generations validated on Standard and Priority. The measured pair completed in 99.109 and 91.178 seconds; one comparison does not establish a general speedup. A later compact run took longer, so the demonstrated improvement is also earlier visibility into real generated work. No fabricated progress or silent shared-object replacement is used.

See `verification-report.md` and the saved evidence for exact test boundaries. This local revision is not deployed. No physical hardware verification or measured user impact is claimed.
