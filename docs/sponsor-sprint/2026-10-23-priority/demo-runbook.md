# Local demonstration

Audience: makers inspecting and modifying hardware. Allow roughly two minutes for an unrehearsed custom generation, then demonstrate an existing generated object if provider latency exceeds the pitch window. Do not claim a saved result is a new live generation.

1. Open the local app on port 3001. Describe a distinct physical object once; click Create device.
2. Show elapsed time, actual component names and those exact parts appearing in 3D while generation continues. Editing remains unavailable until final checks complete.
3. Select a completed component, inspect its role, change a manual property, then Undo. Use the generated mechanism control to illustrate bounded motion.
4. Show the documented Standard/Priority measurements and explain their limited sample size if speed is discussed.

For the hackathon's grounded-design story, use the explicit source Corne study and its existing documents/checks. The custom fan/player is a conceptual illustration, not physically verified engineering.

Before presenting, verify the key/model status and network access without exposing the credential. Keep a saved project available. If generation fails or is cancelled, the prior assembly must remain available. Open that saved object explicitly and label it as a saved result. The public deployment does not contain this local revision.
